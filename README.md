## 알려진 한계 (보고하지 않아도 됨)
- 은행·카드사 직접 웹 스크래핑은 각 금융사 보안모듈·공동인증서 로그인 연동 전까지 `CSV 업로드` 및 로컬 어댑터(또는 오픈뱅킹 토큰 설정 시 오픈뱅킹 API)로 동작합니다.
- 국세청 실전송은 표준 XML 생성 + `XMLDSig` 전자서명 및 익일전송 배치까지 구현되어 있으며, 실제 국세청 서버 전송에는 국세청 표준인증(ASP) 자격이 필요합니다.
- 이메일 발송은 `SMTP_HOST` 미설정 시 로컬 발송 이력(`EmailSentAt`, `SyncLogs`)으로 기록됩니다.
